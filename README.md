# Hospital Management System

Hospital Management System is a Java-based application that helps manage patient records, doctor information, and appointment bookings within a hospital.

## Features

1. **Add Patient:** Record and store patient information, including name, age, and gender.

2. **View Patients:** Retrieve and display a list of all registered patients.

3. **View Doctors:** Retrieve and display a list of all registered doctors, including their specialization.

4. **Book Appointment:** Schedule appointments between patients and doctors, checking for availability.

## Prerequisites

- Java Development Kit (JDK)
- MySQL Database
- MySQL Connector/J (JDBC Driver)
- Your MySQL database should have a schema named "hospital."

## Compile and Run:
- javac HospitalManagementSystem.java
- java HospitalManagementSystem
